# Example Solution for Midterm Practice 1

You will see that this solution is separated into multiple files, not just one main.py. When you have larger projects (such as assignments...) you may need to have separate files like this. **Make sure you review and know how to access things from other files in your main.** 

No external libraries were used, so requirements.txt is empty. No data was imported, so data folder is empty. I kept these there to remind you of proper project structure. 

### These are just *example* solutions. If you have a different method that makes more sense to you, continue using them! As long as you achieve the same result, then you are good to go. 

## Remember: 
* Functions are reusable - define it once and use it again as many times as you want. 
* Once you find an algorithm/function/method etc. that works, use it again in other projects/contexts (all you have to do is modify variables, parameters, return etc.)
