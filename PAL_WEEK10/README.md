# PAL Week 10: Test Driven Development 

This week, we will review TDD (Test Driven Development). The following project will allow you to experiment with 2 different methods of writing Python tests. An example has been provided in each file, so you can observe the output and know what to expect. Your job is to create your own tests, *then* write functions what will pass those tests. 

tests_1.py: 
- Manual testing that does not require the installation of external packages. 

tests_2.py: 
- Uses the pytest unittest framework. 
- You will need to install Pytest for this version. 
- Run 'pip install pytest' in terminal OR go to Extensions and install pytest. 

functions.py: 
- This is where you will write functions AFTER writing their tests (TDD style!)

## Note: 
There are lots of ways to perform unit testing in Python. The most important thing is to test your code often and thoroughly. TDD emphasizes writing tests *before* writing your functions.
