# PAL WEEK 11: OOP - Inheritance

By now, you should have covered all the big concepts in class, so going forward we will review ways to make life easier. This week we will review and practice an important object-oriented programming concept: inheritance. 

The main focus of this week is inheritance, but remember the other OOP principles: 
A: abstraction
P: polymorphism 
I: inheritance
E: encapsulation

While you may not need to use inhertitance extensively in every program you create, make sure you  understand the following: 
- How does inheritance in Python work? 
- When/why would we use inheritance? 
- How does this improve efficiency?
